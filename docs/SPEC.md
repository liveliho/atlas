# Atlas v4 · 产品与工程规格

> 这份文档是对原始需求（「修复专区跳转 bug、清理仓库、优化体验、适配手机与电脑、让它不卡」）的整理与细化，也是 v4 重构的验收标准。以后改版可以直接把它交给开发者或 AI 智能体作为提示词。

## 1. 一句话定位
Atlas 是 GitHub 好项目的中文图鉴：6,000+ 个精选仓库（其中 5,000+ 个 Star 过万），外加 AI 导航、AI 社区和 AI 阅读三个专区。目标用户 70% 在手机上访问。

## 2. 要解决的问题（v3 的根因）
| 现象 | 根因 | v4 的做法 |
|---|---|---|
| 点「AI 导航 / 社区」后白屏一会儿，落到一个空的地方 | 所有内容挤在一个长页面里，6,231 条项目的无限列表夹在中间。跳转时经过列表底部会触发加载，把目标往下推；GSAP 又把新卡片设成透明，看起来就是白屏 | **专区改成独立视图**（hash 路由），切换时直接替换内容并回到该视图上次的位置，不再跨长页面滚动 |
| 手机上卡顿 | 每张卡片都用 `backdrop-filter` 毛玻璃，GSAP 滚动联动和钉住动画，整页 DOM 一直增长，首屏要解析 2.3 MB JSON | 只有顶栏、底栏和弹层用毛玻璃；去掉 GSAP；长列表用 `content-visibility`；数据改成紧凑格式并预加载 |
| AI 导航图标在国内经常加载不出来 | 图标来自 Simple Icons CDN 和 Google favicon 服务 | 32 个 AI 品牌 SVG 图标放进仓库，本地加载 |
| 数据脚本跑不起来 | 脚本都读写 `data/projects.json`，但仓库里只有 57 个分片 | 恢复 `data/projects.json` 作为唯一数据源，删除分片 |

## 3. 信息架构
用 hash 路由区分视图，浏览器的前进 / 后退可以在视图之间切换：

| 视图 | 地址 | 内容 |
|---|---|---|
| 首页 | `#` / `#home` | 标语、搜索框、统计数字、精选合集、Star 前五、三个专区入口 |
| 探索 | `#explore` | 搜索、大类、专业领域、开关筛选、排序、网格 / 列表、无限加载 |
| AI 导航 | `#ai` | 32 款 AI 产品，按对话、创意、编程、搜索分组 |
| 社区 | `#community` | 18 个海内外 AI 社区 |
| 阅读 | `#reading` | 博客好文、经典论文、知识点卡片 |
| 关于 | `#about` | 收录标准、数据来源、更新时间 |

- **旧链接兼容**：`#ai-nav` 指向 `#ai`，`#method` 指向 `#about`；`?q= &cat= &field= …` 仍然可用。
- **深链接**：`?p=owner/repo` 打开时直接弹出该项目详情。
- **滚动位置**：每个视图单独记住自己的滚动位置；第一次进入某个视图时从顶部开始。

## 4. 交互规范
- **手机（< 900px）**：底部固定 5 个标签（首页 / 探索 / AI 导航 / 社区 / 阅读），适配刘海屏安全区；顶栏只保留 Logo、搜索、收藏、主题。筛选放在底部弹层里，项目详情也从底部弹出，触控目标不小于 44px，输入框字号 16px，避免 iOS 自动放大。
- **电脑（≥ 900px）**：顶栏放导航标签，筛选直接摆在工具栏上，项目详情从右侧抽屉滑出，⌘K / Ctrl+K 打开全站搜索，`/` 聚焦搜索框。
- **通用**：
  - 收藏存在本地，支持一键导出为 Markdown 清单；
  - 详情页可复制分享链接；
  - 支持跟随系统 / 浅色 / 深色三种主题，切换时不闪烁；
  - 尊重系统的「减少动态效果」设置。

## 5. 性能预算
- 不依赖任何第三方运行时脚本，自写 JS 压缩前 ≤ 60 KB，CSS ≤ 40 KB，使用系统字体。
- 数据文件 gzip 后约 520 KB（v3 是 650 KB，解析量减半），和 HTML 并行预加载；首页在数据到达前就能完整显示。
- 只对 `transform` 和 `opacity` 做动画；列表卡片使用 `content-visibility: auto`；滚动监听一律 `passive`。
- 在 4 倍 CPU 降速、390×844 的模拟手机上：切换视图时没有超过 100ms 的长任务，搜索输入到出结果不超过 150ms。

## 6. 视觉
- 延续品牌：镂空罗盘星 Logo，强调色为蓝 `#0071e3` 和紫 `#7d7aff`。
- 卡片用纯色表面加细边框，不用毛玻璃；浅色是暖白底，深色是专门调过的蓝黑底。
- 排版：中文用系统黑体，数字用等宽字形；标题字号用 `clamp()` 随屏幕自适应。

## 7. 工程与仓库
- 纯静态站点，GitHub Pages 直接托管，不需要构建步骤。
- 目录：`index.html`、`assets/`（`app.js`、`content.js`、`style.css`、`icons/`）、`data/`（`projects.json` 为源数据，`index.json` 为站点加载的索引）、`scripts/`（数据管线、测试）、`docs/`。
- 删除：57 个数据分片和 `manifest.json`、`split_data.py`、GSAP 动效层、旧版冒烟测试，以及写死在别的机器上的路径。
- 测试：`npm test` 运行 Playwright 冒烟测试，覆盖手机和电脑两种视口，检查视图切换、深链接、搜索、⌘K、详情、收藏、360 到 1440 宽度下无横向溢出、无控制台报错；另有 `python3 scripts/test_classification.py` 分类回归测试。
