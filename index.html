    万星专区

    全站 Star 过万的非 Fork、未归档仓库共 5,399 个，Atlas 收录其中有完整简介的 5,320 个，并逐个打上「万星+」徽章，可一键只看它们。

    按实分类

    按名称、简介与标签判定大类（18 类）、专业领域（16 类）与工作技能；不看容易被刷的 Topic 标签，并有显式纠错表与回归测试把关。

    有用，才收录

    其余精选以 GitHub 实时数据为准入线：综合项目原则上 Star 不低于 600；垂类专业 Skill 受众小，放宽到 20 起，但都必须有清晰简介。剔除 Fork 镜像与已归档项目。

    官方优先

    Model Context Protocol 官方组织、Anthropic、GitHub、Microsoft、OpenAI 等官方出品单独标注「官方」徽章，找权威实现先看它们。
