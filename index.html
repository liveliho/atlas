收录标准

Curated, not crawled blindly.

万星专区

全站 Star 过万的非 Fork、未归档仓库共 5,399 个，Atlas 收录其中 5,320 个（其余为无简介项目），并逐个打上「万星+」徽章，可一键只看它们。

有用，才收录

其余精选项目以 GitHub 实时数据为准入线：综合项目原则上 Star 不低于 600；垂类专业 Skill（法律、医疗、金融等）受众小，放宽到 20 起，但都必须有清晰简介。

逐个标注专业

每个项目按名称、简介与标签判定所属大类（18 类）、专业领域（16 类）与具体工作技能（如 SEO 优化、渗透测试、合同审查），卡片上一眼可见，也能按领域筛选。

去伪存真

剔除 Fork 镜像与已归档项目；分类不看容易被刷的 Topic 标签，而是按项目名称与简介的真实内容重新归类，避免蹭标签的项目混进 MCP / Skills 区。

官方优先

Model Context Protocol 官方组织、Anthropic、GitHub、Microsoft、OpenAI 等官方出品单独标注「官方」徽章，找权威实现先看它们。

持续更新
