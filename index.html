How we curate收录标准

有用，才收录

以 GitHub 实时数据为准入线：综合项目原则上 Star 不低于 600；垂类专业 Skill（法律、医疗、金融等）受众小、星标天然低，放宽到 20 起，但同样要求有清晰的项目简介。无简介、难判断用途的项目不收。

逐个标注专业

每个项目都按名称、简介与标签逐项判定，标注所属专业领域（软件开发、市场营销、网络安全、金融与交易、法律与合规等 16 类）与具体工作技能（如 SEO 优化、渗透测试、合同审查），卡片上一眼可见，也能按领域筛选。

去伪存真

剔除 Fork 镜像与已归档项目；分类不看容易被刷的 Topic 标签，而是按项目名称与简介的真实内容重新归类，避免「蹭标签」的项目混进 MCP / Skills 区。

官方优先

Model Context Protocol 官方组织、Anthropic、GitHub、Microsoft、OpenAI 等官方出品单独标注「官方」徽章，找权威实现先看它们。

持续更新

数据来自 GitHub 搜索 API 的实时抓取（抓取脚本就在本仓库里）。发现遗漏的好项目，欢迎到仓库提 Issue 推荐收录。
